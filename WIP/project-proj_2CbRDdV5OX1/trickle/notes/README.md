# Creative Portfolio

A sleek, minimalist portfolio website featuring categorized project galleries and image carousels for each project.

## Features
- **Project Categories**: Easily filter projects by category (e.g., Web Design, Photography, Branding).
- **Image Carousels**: Each project card features a built-in image carousel to showcase multiple photos.
- **Responsive Design**: fully responsive layout using TailwindCSS.

## Architecture
- `app.js`: Main application entry point and layout definition.
- `components/Header.js`: Navigation header.
- `components/ProjectGallery.js`: Handles category filtering and displays the project grid.
- `components/ProjectCard.js`: Individual project presentation.
- `components/Carousel.js`: Reusable image carousel component.
- `components/Footer.js`: Site footer.
